## 1. HISTORICAL PERCENTAGE SOURCE VERIFICATION
- **Source**: Calibrated historical probability generated by `HistoricalEvidenceService` (`src/services/historical_evidence_service.py`) querying matching market regimes, sessions, and setups from the `historical_signals` table in `historical_market_data.db`.
- **Decision Engine Assembly**: `DecisionService._build_three_layer_signals` (lines 560–635 of `src/services/decision_service.py`):
  - If historical sample size $< 20$ or status is `"INSUFFICIENT_SAMPLE"`, `hist_pct` is strictly set to `None`, and `HistoricalMarketSignal.percentage = None`.
  - If historical sample size $\ge 20$ and status is `"AVAILABLE"`, `hist_pct = round(hist_prob)` (or fallback win rate).
- **API Payload**: Exposed at `data.decision.historical_signal.percentage`.
- **Truth Invariant**: Sub-threshold historical sample sizes never manufacture synthetic percentages.

## 3. HISTORY + NOW $\to$ OVERALL PERCENTAGE VERIFICATION
- **Calculation Formula**:
  $$\text{Overall Insight \%} = \text{round}\left(\frac{\text{safeHistPct} + \text{safeNowPct}}{2}\right)$$
  Implemented in `frontend/src/lib/format.ts`: `computeOverallInsightPercentage(safeHistPct, safeNowPct)`.
- **Presentation Integration**: Rendered in `OverallMarketSignalHero` in `frontend/src/app/page.tsx`:
  - If `safeHistPct` is `null` (e.g. sample $< 20$ or insufficient sample) or `safeNowPct` is `null`: returns `null` (`--%`).
  - If market is closed (`isWeekendClosed`): returns `null` (`--%`).
  - **NEVER returns `0%`** as a fallback for missing data.
- **Backend Evidence Fusion**: `SignalAggregator.aggregate()` fuses Now Market, Historical Evidence, ML Conviction, and Validated Strategy into an overall score. If direction gate fails or market is in conflict, `overall_signal.percentage = None` with signal `WAIT`.

## 6. SIGNAL $\to$ FORWARD SHADOW CAPTURE & RESOLVER OUTCOME DETERMINATION
- **Capture Layer**:
  - `ForwardShadowEngine.capture_forward_signal()` captures pre-trade directional signals into `forward_shadow_signals` with unique cryptographic SHA-256 hash IDs (`FWD-BTC-...`, `FWD-XAU-...`).
  - `MLShadowService.generate_prediction()` logs all observations into `ml_shadow_observations`.
- **Resolver Logic (`ForwardShadowResolverWorker`)**:
  - Evaluates subsequent closed 5m candles chronologically after $T_0$.
  - Directional BUY: High $\ge$ TP $\to$ `RESOLVED_WIN`; Low $\le$ SL $\to$ `RESOLVED_LOSS`.
  - Directional SELL: Low $\le$ TP $\to$ `RESOLVED_WIN`; High $\ge$ SL $\to$ `RESOLVED_LOSS`.
  - Conservative SL Priority: If both SL and TP are hit in the same bar, conservatively resolved as `RESOLVED_LOSS`.
  - Non-trade WAIT: Observations without SL/TP are resolved as `OBSERVED_WAIT` with realized $R = 0.0$.
